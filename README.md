# Mobility-project

El objetivo de este análisis es evaluar la correlación entre la productividad económica y la congestión vehicular en las principales ciudades latinoamericanas. Para ello, se utilizaron datos de TomTom Traffic Index, específicamente la variable jams_delay (minutos de retraso por congestión de tráfico), y datos de OECD Cities, a través de la variable city_gdp_capita (PIB per cápita).

Para este análisis se utilizó información del año 2024, correspondiente a 15 ciudades distribuidas en 7 países.
